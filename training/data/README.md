# 问题主题教学数据

共 104 条手工编写的中文教学问题，固定划分为训练 64、验证 16、测试 24；每个集合四类均衡。不是采集的真实用户数据，也没有覆盖开放领域。

- `auth`：身份认证、登录、Token、API Key，包括令牌失效。
- `rate_limit`：配额、请求频率、429/42901、退避等待。
- `failure`：系统故障、网络/数据库异常、500/502/503、超时、文件解析失败。
- `other`：上述三类以外的学习、生活、闲聊等教学样本。

`split` 在训练前固定。每两个问题有组标识，同组不跨集合；训练脚本检查标准化重复文本和组标识。人工近义改写仍可能共享相同主题词，这不是严格的陌生领域泛化测试。

验证集只用于选置信阈值，测试集不参与训练和选阈值。增加数据后应保留独立、人工复核的测试集；同一问题的改写和同一来源的重复样本应放在同组。

输出的置信分数不是经过校准的真实正确概率；教学测试全部正确也不代表真实用户问题全部正确。低分问题输出“未确定”，不会替用户切换 RAG/CHAT 模式。
