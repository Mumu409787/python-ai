怎么看待这些结果？

混合检索与改写均有离线回归；真实服务联调验证新增、去重、删除与记忆，模型使用替身。小范围召回对照独立保存，不宣称总体准确率或速度提升。历史 Ragas 报告保留在 evaluation/。

检查点保存完整会话，不是全链路断点续跑；分类器是小样本教学模型，OCR 仍可能有错字。LoRA 只完成条件评估，未执行大模型微调。BM25 当前每次读取全部已入库片段，适用于小型知识库；资料变多后需改为持久索引。PostgreSQL 与 Qdrant 之间没有分布式事务。

TRY IT, THEN TRUST IT

用十三个案例，亲手验收。

建议按顺序体验。问答内容可能变化，判断标准看事实、引用和状态。

打开完整验收指南 ↗
CASE 01 上传与去重

一份资料，只入库一次。

回工作台连续两次点击“载入示例”。第一次创建文档或提示已存在，第二次应显示“内容已存在”，且文档 ID 相同。

验收标准文档列表不增加重复项，第二次不重复向量化。
CASE 02 有依据的回答

Token 到底能用多久？

先载入星链网关示例，再发送“访问 Token 的有效期是多久？”

验收标准答案包含“2 小时”并带 [序号]；右侧原文能找到对应依据。
CASE 03 资料不足

不知道，也是一种正确回答。

在只有网关资料的知识库中询问“推荐几家好吃的火锅店”。如果你的库里另有餐饮资料，请换成库外问题。

验收标准无命中时固定回答“根据现有知识库资料，无法回答该问题。”，右侧引用为 0。
CASE 04 流式与非流式

看见答案逐步出现。

打开“流式输出”，问网关超时；再关闭开关发送同样问题，对比呈现方式。

验收标准流式正文逐步出现；非流式等待后一次展示。两者事实都应是 30 秒，超时返回 504。
CASE 05 会话记忆

它能记住上一轮吗？

切换“普通聊天”，新建会话。先说“请记住我的毕业设计代号是青竹-472。”，再问“我的毕业设计代号是什么？”

验收标准同会话应回答“青竹-472”；新会话不会携带这段历史。默认使用 PostgreSQL 检查点。
CASE 06 删除验证

资料删除，引用随之消失。

上传自己的临时测试文档，例如写入“苍鹭测试服务端口是 18743”。确认能问到后，仅删除这份临时文档，再问同一问题。

验收标准列表无该文档；后续引用不再包含它。若有其他资料，可能仍命中其他文档。
CASE 07 异常与恢复

出错时，给出明确反馈。

上传不支持的文件或损坏的 PDF，查看错误提示。超时、限流、并发冲突和部分写入用自动化测试验证，无需故意停掉服务。

验收标准上传错误可见；不会假装成功。异常回答不保存为完整一轮；回归测试覆盖故障分支。
查看回归测试命令 ↗
CASE 08 混合检索

错误码也能直接查。

先载入星链网关示例，再发送“42901”。也可以问“/auth/refresh 有什么作用？”

验收标准42901 对应触发限流，并有包含该错误码的来源。是否优于原方案，以固定题集对照为准。
CASE 09 追问改写

“那刷新用的呢？”

知识库新会话先问“访问 Token 的有效期是多久？”，等回答完成再问“那刷新用的呢？”。不要中途新建会话。

验收标准检索问题补全 Refresh Token，回答为 7 天并有来源。答案下方可查看实际检索问题；改写失败会明确提示回退。
CASE 10 持久检查点

重启服务，仍记得上一轮。

普通聊天记住“雪松-638”，保留当前会话，在 PowerShell 停止并重启本项目服务，再追问代号。

验收标准同编号、同模式、有效期内可回忆；答案下方显示“会话已保存”。
查看重启步骤 ↗
CASE 11 调用追踪

看见答案走过的每一步。

正常问一次 42901，回答完成后点“查看调用链”，进入自己的 Langfuse Cloud 项目。

验收标准有根 trace、检索、生成、记忆读写；默认不上传问题和资料正文。
CASE 12 训练后的分类

这是什么主题的问题？

问“访问令牌多久过期”，在答案下方查看“模型主题：认证”。低置信度显示未确定；分类不改变问答证据规则。

验收标准本地模型参与推理，有固定测试集及失败案例；不把小样本指标当作生产准确率。
CASE 13 OCR 与页码

图片里的文字，也能成为依据。

下载混合 PDF 样本，回到工作台点击上传区域选择它。新会话问“CRANE-18743 对应的图像服务端口是多少？”

验收标准端口 18743，右侧引用第 2 页；中文名称可能有 OCR 偏差，需核对原件。

快捷按钮只切换模式并填入问题，点击“发送”才会调用模型。有历史的知识库问题最多额外调用一次改写模型；首轮和普通聊天不调用改写。故障回归与模型质量不能互相替代。
